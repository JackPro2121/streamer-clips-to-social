# Runtime dependencies. Dev/test tooling lives in requirements-dev.txt.
#
# Install through tools/install_deps.sh, not `pip install -r requirements.txt`
# directly. Three packages in the transitive graph (scenedetect, rapidocr, and
# previously mediapipe) each declare a *different* OpenCV distribution, and all
# of them install into the same `cv2/` package directory. Installing this file
# naively leaves three distributions fighting over one directory, so the
# effective `cv2` build depends on pip's install order. install_deps.sh removes
# the non-headless variants after the fact, which is deterministic.
